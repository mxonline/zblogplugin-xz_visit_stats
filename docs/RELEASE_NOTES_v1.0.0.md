# xz_visit_stats v1.0.0 发布说明

发布时间：2026-08-23

## 功能范围

- 访问统计与访问记录
- 蜘蛛分析
- 来源分析
- IP 分析
- SEO 报告
- 实时访问
- 数据维护

## 安装包

安装包根目录为 `xz_visit_stats/`，包含插件代码、后台资源和维护文档。解压至 `zb_users/plugin/` 后，在 Z-BlogPHP 后台启用插件即可。

## 发布验证

- 发布包内容与发布源文件哈希一致。
- 隔离安装测试已验证日志表、核心字段、必要索引、采集数据写入、实时读取、激活和后台权限检查。
- 全部插件 PHP 文件通过语法检查。

## 兼容性说明

插件遵循 Z-BlogPHP 插件结构，后台页面要求 `root` 权限。访问日志使用现有插件表，不修改 Z-BlogPHP 核心数据结构。
