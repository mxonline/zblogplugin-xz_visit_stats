# xz_visit_stats v3.0.2 发布说明

v3.0.2 是 v3.0.0/v3.0.1 的 UI-SPEC 最终收口修复版本，产品定位仍为“站长访问分析中心”。

## 本次修复

- 后台使用真正的插件内部左侧分组导航，右侧显示主内容。
- 总览首屏优先展示 KPI 与 PV/UV/IP、24 小时、来源、访客环境等 ECharts 图表。
- 移动端导航由本地 Alpine.js 控制展开/收起。
- 访问记录保留右侧详情 Drawer、Esc 关闭和安全文本转义。
- DurationMs 服务端耗时与 RUM/Core Web Vitals 继续分区展示。
- 修正 `admin.css` 的资源版本参数为 `3.0.2`。

## 兼容与范围

- 与 v3.0.0、v3.0.1 的数据库结构和统计口径兼容。
- 本版本不创建、删除、授权或修改数据库，不改变历史访问数据。
- 本轮未执行独立数据库 parity；该专项不纳入本次 UI 发布门禁。
- 不修改 v3.0.0/v3.0.1 Tag 或 Release。

安装包：`xz_visit_stats-v3.0.2.zip`
