# xz_visit_stats v2.0.0 发布说明

## 核心变化

v2.0.0 将插件定位为“站长访问分析中心”，保留 v1.3 原始访问事实表，并增加 PathKey、日级汇总和汇总状态结构，降低历史趋势查询成本。

## 七个后台模块

总览、访问记录、页面分析、来源分析、蜘蛛分析、错误分析、设置与维护。

模块统一使用 Z-Blog 站点时区和冻结的真人/蜘蛛统计口径，主要统计支持下钻和组合筛选。

## 升级与兼容

从 v1.3 升级时保留历史日志；迁移可重复执行。PathKey 历史回填和日汇总可分批执行、暂停后继续，并可安全重建。新安装与升级最终使用相同的原始日志、PathKey、日汇总和汇总状态结构。

## 统计说明

- VisitorHash 是匿名统计标识，不是用户账号身份。
- DurationMs 是服务端处理耗时，不是用户停留时间。
- 关键词仅解析 Referer 实际携带且可解析的内容，不代表完整关键词排名。
- 真人 UV/IP 在跨日查询中精确去重，不直接相加每日 UV/IP。

## 性能与已知限制

100k 和 1m 原始日志已实际验证；10m 未做真实压测，不承诺千万级复杂聚合为毫秒级。日汇总用于降低历史趋势查询成本，精确跨日 UV/IP 仍有高基数成本。来源函数解析、深分页和大范围精确去重仍应控制查询窗口。
