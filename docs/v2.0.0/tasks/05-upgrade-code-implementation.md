# xz_visit_stats v2.0.0 Task 05

## 目标

实现 v1.3 到 v2.0 的升级代码框架。

## 开发内容

创建升级目录：

```
inc/upgrade/
```

新增文件：

- version.php
- checker.php
- runner.php
- migrate_2_0.php

## 要求

- 不影响 v1.3 已安装用户
- 支持自动检测数据库版本
- 支持重复执行保护
- 升级失败不能破坏原数据
- 所有数据库操作需要异常处理

## 流程

插件启动

↓

读取当前数据库版本

↓

判断是否需要升级

↓

执行迁移

↓

更新版本记录

## 测试

- 新安装测试
- v1.3升级测试
- 重复升级测试
- 数据完整性测试
