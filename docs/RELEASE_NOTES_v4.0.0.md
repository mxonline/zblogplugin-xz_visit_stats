# xz_visit_stats v4.0.0 Release Candidate

**状态：候选版；T5 Release Gate PASS，尚未正式发布。** 本机 Windows 验收、复审后的后台筛选/空状态与 680/800/1100 px 响应式复测、精确 SHA CI 和正式 ZIP Dry Run 均通过。尚无正式 Tag、GitHub Release 或应用中心版本。

## 本版本内容

- 新增访问总览、实时访客、趋势、访问记录、来源、内容、访客、蜘蛛、事件与设置分析页面。
- 新增会话与页面序列、生命周期停留时长、单页会话跳出指标、事件参数白名单、IP/CIDR 规则和受控 CSV 导出。
- 在保留 v3 原始访问日志与既有汇总的前提下增量增加 v4 数据表；迁移可重复执行。
- 继续区分访客停留时长与 `vs_DurationMs` 服务端处理耗时。v3 历史行没有会话生命周期数据时不补造停留或跳出指标。
- 默认关闭 Beacon；只有站长启用后才接收页面生命周期与事件请求。
- 修正窄屏下插件内容被 Z-Blog 固定侧栏覆盖并产生横向溢出的布局；管理页保留框架导航内距，窄屏模块菜单可折叠。

## 兼容性

- PHP 7.1 语法下限；本轮真实 Windows 验收环境为 PHP 8.3.8、Z-BlogPHP build 173540、IIS 10、MySQL 5.7.38。
- 保持插件 ID `xz_visit_stats`，安装目录仍为 `zb_users/plugin/xz_visit_stats`。
- v3 → v4 升级步骤和数据保留边界见 [升级说明](v4.0.0/UPGRADE-v3-to-v4.md)。

## 已知限制

- 升级前的访问记录不具备 v4 会话/页面生命周期数据，因此历史时间段的停留和跳出覆盖率可能显示为部分或不可用。
- 蜘蛛识别基于 User-Agent，不进行反向 DNS 或官方 IP 段真实性校验。
- T5 本机数据集用于功能与查询计划验收，不代表千万级日志压测；详细边界见 [T5 验收记录](v4.0.0/T5-ACCEPTANCE-2026-10-13.md)。
