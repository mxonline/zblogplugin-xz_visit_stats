# xz_visit_stats v3.0.0 发布说明

v3.0.0 将插件统一为站长访问分析中心，覆盖总览、实时分析、访问记录、页面、来源、推广活动与 AI 来源、IP、访客环境、蜘蛛、错误、性能和设置与维护模块。

主要内容：

- 图表化总览、实时刷新、页面与入口分析、来源/UTM/AI 维度、AI 爬虫和错误关联；
- Keyset 连续读取、周期对比、服务器响应耗时分位数与慢请求分析；
- 可选同源 Beacon/RUM，采集页面加载体验、屏幕、视口和语言；
- 保留历史日志，迁移、回填和汇总任务可重复执行，不创建或删除数据库；
- 后台术语、详情抽屉、空状态与响应式布局完成最终验收。

兼容性与限制：保留 v2.x 历史日志与升级路径；地域库不可用时安全降级；VisitorHash 是匿名统计标识，服务器响应耗时不代表停留时长。

安装包：`xz_visit_stats-v3.0.0.zip`
