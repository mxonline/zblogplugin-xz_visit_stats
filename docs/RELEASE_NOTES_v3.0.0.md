# xz_visit_stats v3.0.0 发布说明（开发中）

当前版本依据 `docs/v3.0.0/PRD-v1.0.md` 开发，尚未创建正式 Tag、Release 或正式安装包。

## 方向

- 完整访问统计与分析中心：图表化总览、实时分析、IP、访客环境、来源/Campaign、AI 来源、蜘蛛、错误和性能分析。
- 保留 v2.0.1 原始访问事实表和统计口径，新增维度可从历史数据可靠派生时再分批回填；不能可靠回填的历史字段标记为升级后可用。
- 可信代理以 REMOTE_ADDR 为信任根；没有离线地域能力时地域为空降级，不调用外部 API 阻塞采集。
- DurationMs 始终表示服务端处理耗时；VisitorHash 不是登录用户身份。

## 当前限制

- 图表、地域数据库适配、历史回填、CSV与完整升级回归仍在开发/验收中。
- 1000万规模如未实际压测，不作毫秒级复杂聚合承诺。
