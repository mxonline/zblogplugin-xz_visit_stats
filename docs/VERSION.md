# xz_visit_stats 版本信息

## 当前版本

当前版本：**v3.0.0**

产品定位：**站长访问分析中心**。

v3.0.0 在保留历史访问日志和 v2.x 兼容结构的基础上，提供图表化总览、实时分析、页面/来源/IP/访客环境/蜘蛛/错误/性能分析、推广活动与 AI 来源，以及设置与维护模块；迁移、回填、汇总和可选 Beacon 均保持可重复或可关闭。

## 兼容说明

- v1.3 → v2.0 升级保留历史日志，不修改历史访问记录。
- 迁移可重复执行；PathKey 回填和日汇总支持分批、恢复和重建。
- VisitorHash 不是用户账号身份。
- DurationMs 是服务端处理耗时，不是停留时长。
- 关键词只展示 Referer 实际携带且可解析的内容。

## 性能限制

- 100,000 和 1,000,000 行原始日志已实际执行基准。
- 10,000,000 行未实际压测，结果仅作风险估算。
- 日汇总降低历史趋势查询成本；精确跨日 UV/IP 仍需原始日志范围内去重。
- 不对千万级复杂聚合承诺毫秒级响应。
