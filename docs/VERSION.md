# xz_visit_stats 版本信息

## 当前版本

当前开发版本：**v4.0.0 Release Candidate**（未正式发布；尚无 Tag / GitHub Release）。

产品定位：**站长访问分析中心**。

v4.0.0 在保留 v3 原始访问日志和既有汇总结构的基础上，提供访问总览、实时访客、趋势、记录、来源、内容、访客、蜘蛛、事件与设置分析，并增加会话页面序列、停留/跳出指标、IP/CIDR 过滤和受控导出。Beacon 默认关闭。

T5 Windows 本机验收、680/800/1100 px 后台视图复测、精确 SHA CI 与 94 项安装包核验均已通过；Release Gate 为 PASS。v4.0.0 仍是候选版，尚无正式 Tag 或 GitHub Release。详细证据见 [T5 本机验收记录](v4.0.0/T5-ACCEPTANCE-2026-10-13.md)。

兼容性基线：PHP 7.1 语法下限，实际验收 PHP 8.3.8 / Z-BlogPHP build 173540 / MySQL 5.7.38。

## 兼容说明

- v3.0 → v4.0 采用增量迁移并保留历史访问记录；重复迁移不重复创建表或索引。
- v1.3 → v2.0 升级保留历史日志，不修改历史访问记录。
- 迁移可重复执行；PathKey 回填和日汇总支持分批、恢复和重建。
- VisitorHash 不是用户账号身份。
- DurationMs 是服务端处理耗时，不是停留时长。
- 关键词只展示 Referer 实际携带且可解析的内容。

## 性能限制

- 100,000 和 1,000,000 行原始日志已实际执行基准。
- 10,000,000 行未实际压测，结果仅作风险估算。
- 日汇总降低历史趋势查询成本；精确跨日 UV/IP 仍需原始日志范围内去重。
- 不对千万级复杂聚合承诺毫秒级响应。
