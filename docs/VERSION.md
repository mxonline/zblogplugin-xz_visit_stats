# xz_visit_stats 版本路线

## 当前状态

当前版本：**v1.1.0**（正式发布候选版）。

v1.0.0 已正式发布；v1.1.0 在不调整采集逻辑和数据结构的前提下，优化后台筛选、数据展示和 SEO 来源分析。

后台已提供以下入口：

- 统计概览：`main.php?view=overview`
- 访问记录：`main.php?view=records`
- 蜘蛛分析：`main.php?view=spider`
- SEO 报告：`main.php?view=seo`
- 来源分析：`main.php?view=source`
- IP 分析：`main.php?view=ip`
- 数据维护：`main.php?view=maintenance`
- 实时访问：`main.php?view=realtime`

说明：`plugin.xml`、本文档和变更记录已统一为 `1.0.0`。本轮仅进行发布整理，不引入 v1.1 功能。

## 版本维护规则

- 每个版本以可验收的功能边界组织，不在维护版本中混入未定义的新业务模块。
- 新版本开始前先确认已有时间范围、分页、权限和转义接口可否复用。
- 涉及采集或数据结构的变更须补充安装/升级兼容性验证。
- 每次版本完成后更新 `CHANGELOG.md`、完成 PHP 语法检查并进行核心 SQL 抽查。
- 对外发布前，审查 `plugin.xml` 的版本、说明、发布日期和兼容性声明。
