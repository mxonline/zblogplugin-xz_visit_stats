# v3.0 表格布局与响应式验收

日期：2026-08-25

## 改造

- 普通表格统一使用 `width: 100%` 和固定布局；文本列可截断，完整访问详情继续在 Drawer 查看。
- 访问记录主列表仅保留访问时间、类型、页面、来源（1366px）、状态、耗时、详情；IP、蜘蛛、浏览器、操作系统和设备信息移至 Drawer。
- 移除访问记录的 `min-width: 1320px` 与普通列表横向滚动；详情操作列始终保留。
- 1024px 隐藏来源等次要列；390px 的访问记录变为纵向紧凑卡片，保留详情入口。
- 非访问记录的普通统计表在窄屏隐藏中间次要列，但保留首列与最后操作列；未将普通列表归入可横向滚动例外。

## 本机实机验收

检查方式：已登录本机 Z-Blog 后台，验证插件内容区 `scrollWidth`、表格容器 `scrollWidth` 与可视宽度。

| 宽度 | 访问记录 | 总览/页面/来源/推广/IP/环境/蜘蛛/错误/性能/设置 |
|---:|---|---|
| 1366px | PASS，无横向溢出；七个核心列与详情可见 | PASS，所有检查页面无插件内容或表格容器横向溢出 |
| 1024px | PASS，隐藏来源等次要列，详情可见 | PASS |
| 768px | PASS，六个核心列与详情可见 | PASS |
| 390px | PASS，纵向紧凑卡片、详情入口可见 | PASS，插件主内容无横向溢出 |

## 结论

普通后台业务列表不再依赖横向滚动完成主要操作。Drawer 保留完整记录信息；没有为本次改造删除或修改原始日志。
