# v3.0 真人产品团队 UI / 文案审查

日期：2026-08-25

## 结论

PASS。审查以本机已登录 Z-Blog 后台逐页打开为依据，覆盖总览、实时分析、访问记录、页面分析、来源分析、IP 分析、访客环境、蜘蛛分析、错误分析、性能分析、设置与维护，以及推广活动与 AI 来源扩展页。

## 产品经理视角

- 内部导航按概览、流量分析、访客分析、技术分析、系统分组；当前页有选中态。
- 每页有明确标题、时间范围或工作说明；空数据不使用技术错误替代。
- 服务器处理耗时与真实用户体验分区，避免把浏览器体验当成服务器性能。

## 前端 / 交互视角

- 桌面端为侧栏与内容区；390px 下插件内容区不横向撑出，模块导航可展开。
- 总览实测 ECharts canvas；记录详情 Drawer 可开关；实时页为同源 AJAX，隐藏页面暂停，失败显示提示并自动重试。
- 文本输出仍经 PHP 转义或 JS `textContent` 写入；无公网 ECharts/Alpine 依赖。

## 普通站长视角

- 将导航中的 `Campaign / AI 来源` 改为“推广活动与 AI 来源”。
- 将界面中的 `Path`、`Referer`、`Browser`、`Device`、`AI crawler` 等字段转成中文可理解名称；保留必要技术缩写时加入中文说明。
- 地域库不可用、Beacon 未产生数据、历史标题缺失等情况提供解释性空状态，而非开发术语。

## 仍保留的必要术语

PV、UV、IP、URL、UTM、AI、RUM、LCP/INP/CLS/TTFB/FCP 为统计领域常用缩写；界面在相应区域提供中文标题或说明，不以缩写作为唯一含义。
