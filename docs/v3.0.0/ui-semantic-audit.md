## 共用修复

- Drawer 由结构化的 `window.XZVS_RECORDS` 驱动，按访问、页面、来源与访客分组；不再按表格单元格序号展示“字段 N”。
- 空值统一使用业务语义：真人的蜘蛛名称为“非蜘蛛”、无来源为“直接访问 / 无来源”、未知浏览器为“未识别浏览器”、历史标题缺失为“升级前无标题数据”。
- HTTP 状态在 Drawer 中同时展示站长可读说明，如 `200 · 正常`、`404 · 页面不存在`、`500 · 服务器错误`。
- 页面内默认隐藏匹配 `__xz`、`xz_t5`、`v3-` 的本机测试路径，提供“显示测试记录”按钮；不修改任何原始日志。
- 将来源类型、设备类型和常用字段转为中文；保留 PV、UV、UTM、AI、RUM 与 Web Vitals 缩写时配合中文名称说明。
