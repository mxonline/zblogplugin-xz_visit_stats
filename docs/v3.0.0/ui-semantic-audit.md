- Drawer 由结构化的 `window.XZVS_RECORDS` 驱动，按访问、页面、来源与访客分组；不再按表格单元格序号展示“字段 N”。

- 将来源类型、设备类型和常用字段转为中文；保留 PV、UV、UTM、AI、RUM 与 Web Vitals 缩写时配合中文名称说明。
