## v2.0.0｜站长访问分析中心

### 状态

- 版本：v2.0.0
- 状态：正式发布准备完成。

### 数据核心与查询

- 保留 v1.3 原始访问日志，新增规范化 PathKey、日级汇总和汇总状态结构。
- 支持可重复、可恢复的迁移、PathKey 分批回填、日汇总生成与安全重建。
- 统一真人 PV/UV/IP、蜘蛛 PV、状态码、来源、页面和服务端处理耗时统计口径。
- 多日 UV/IP 继续在原始日志范围内精确去重，不直接相加每日 UV/IP。

### 后台模块

- 统一“访问分析”主入口，提供总览、访问记录、页面分析、来源分析、蜘蛛分析、错误分析、设置与维护七个模块。
- 支持站点时区、今天/昨天/7天/30天/自定义范围、最近 5/15/30 分钟和组合筛选。
- 主要统计支持下钻到访问记录；后台输出对 URL、Referer、UA、Path 和 IP 做转义。
- 写操作保留管理员权限与 CSRF 校验。

### 兼容与限制

- v1.3 → v2.0 保留历史原始日志，不建立旧的关键词、独立错误原始表或安全表。
- VisitorHash 是匿名统计标识，不是用户账号身份。
- DurationMs 表示服务端处理耗时，不代表用户停留时间。
- 关键词只解析 Referer 实际携带且可解析的内容，不承诺完整关键词排名。
- 100k 和 1m 原始日志已实际基准验证；10m 未实际压测，不承诺千万级复杂聚合为毫秒级。
- 日汇总用于降低历史趋势查询成本；精确跨日 UV/IP 仍有高基数成本。
