# 来源 URL 识别与悬停详情

在现有 `vs_Referer`、来源域名、来源类型和搜索引擎识别逻辑基础上增强来源分析页面。

## 目标
- 默认表格不再铺开超长 Referer。
- 能快速看出具体来源站点/搜索来源。
- 鼠标悬停时查看完整来源信息。
- 不增加数据库字段，不破坏现有来源筛选、分页和统计。

## 开发要求
1. 先复用 `inc/source_stats.php` 现有 host/type/search-engine 逻辑。
2. 优先新增一个可复用的 Referer 展示/解析辅助函数，避免在 `main.php` 堆条件判断。
3. 默认列表显示紧凑来源信息：
   - 优先识别来源名称
   - 不能识别时显示域名
4. 悬停详情至少包含：
   - 完整 Referer URL
   - 来源域名
   - 来源类型
   - 搜索引擎名称（能识别时）
   - 搜索关键词（仅在 URL 参数中能可靠得到时）
5. 支持常见搜索来源：
   - 百度
   - Bing
   - Google
   - 搜狗
   - 360
6. 不伪造搜索关键词；Referer 中拿不到就显示“未提供”或不显示关键词。
7. 所有 URL/文本输出必须 HTML 转义，防止后台 XSS。
8. 超长 URL 不能撑宽表格。
9. 移动端和窄屏不能出现明显布局破坏。
10. 不改数据库结构。
11. 不改现有 GET 参数。
12. 不提交 Git。

## 验证
- 普通外链
- 百度/Bing/Google 等搜索 Referer
- 无法识别的 Referer
- 超长 Referer
- 带中文和特殊字符的 Referer
- 空 Referer 不进入来源链接明细的现有语义保持不变
- `git diff --check`
- PHP/JS 快速语法检查（工具存在时）
