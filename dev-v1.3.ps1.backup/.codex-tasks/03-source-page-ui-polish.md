# 来源分析页面第二轮细节收口

只在 Referer 悬停详情完成后做轻量 UI 收口。

## 目标
让来源分析页面在首屏更紧凑，保持与其余 4 个筛选页面统一。

## 检查/优化点
1. 查询按钮与“高级筛选”按钮保持相邻，不要被推到最右侧。
2. 常用下拉框桌面端不要无限拉伸，保持约 220~300px 的合理宽度。
3. 常用筛选区域靠左紧凑排列。
4. 小屏幕允许自然换行。
5. 不为来源分析写不必要的独立布局规则；优先共用现有筛选样式。
6. 不改变查询逻辑、不改变 GET 参数、不改变数据库。
7. 若当前页面已经满足这些要求，只报告“无需修改”，不要为了任务而改代码。

## 验证
- 来源分析
- 访问记录
- 蜘蛛分析
- SEO 报告
- IP 分析
- `git diff --check`
